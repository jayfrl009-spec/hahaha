# AFTER THE BELL.

A tiny browser-based school horror game by JX LABS.

## Play
Open `index.html` in a browser, or enable GitHub Pages:
1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. When GitHub Pages finishes deploying, open the URL it provides.

## Controls
- **WASD / Arrow keys:** Move
- **E:** Pick up the key / interact with the exit

## Objective
Find the key, avoid the watcher, and reach the exit. The game is made with plain HTML, CSS, and JavaScript; no build step is required.
